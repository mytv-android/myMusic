同步位置

使用 GitHub 账号创建一个私密 Gist，或连接已有 Gist。

创建 GitHub 令牌

需要 gist 权限。令牌不会写进同步文件，也不会被此网页保存。

也可以粘贴已有文件的完整链接。

请在手机与电视连接同一可信局域网时使用。

正在连接

会同步什么

自建歌单、收藏、歌曲元数据和平台账号 Cookie。Cookie 会以明文写入私密 Gist / 代码片段，请勿公开文件链接。

不会包含

最近播放、下载文件、播放地址和播放进度。Gist / Gitee 访问令牌只用于连接，不会写进同步文件。

  1. 电视验证令牌，并创建或读取云端文件。
  2. 如果本机和云端都有歌单，在电视大屏上选择首次合并方式。
