结论

Apple 没有公开歌词页的动画参数。这里的数都取自 AMLL：它是照 Apple Music 歌词页做的开源组件，源码注释里写明了哪些值是对着 Apple Music 调的（例如渐变宽度「模拟 Apple Music for iPad 的效果，可以设置为 0.5」）。切歌部分只用 Apple 官方文档里写到的行为。 现有的经典和 Rush 换行时整列一起滚；Apple Music 的感觉来自每句各有一个弹簧、从上往下一句晚 50 毫秒出发，再加上当前句只比别的句子大 3%、别的句子按距离发虚。

经典模式：现在怎么换句，按 M3E 怎么调

默认的「经典」就是宿主自己的歌词列（PlayerParts.kt 的 LyricsList），手机、平板、折叠屏、电视用的都是它。现在换一句时： 整列一个弹簧把当前句的中心滚到视口 42% 处（平板 44–46%），用的是 MotionScheme.expressive 的 slowSpatial（阻尼比 0.8、刚度 200）； 当前句用同一个弹簧从 82% 长到 100%（手机放大 1.22 倍，平板、电视 1.36–1.42 倍），所有句按放大后的字号排版、只缩不放； 透明度 100 / 60 / 38%、隔两句以上模糊 1.4 dp，用 defaultEffects（临界阻尼、刚度 1600）； 字重从 SemiBold 直接换成 Black；逐字填色层直接换上，没唱到的部分 45%。 换歌时直接换成新歌词、定位到当前句，没有过渡；手动滚动后停 3 秒滚回来。

M3E 的弹簧怎么分工

位置、大小、形状用 spatial（阻尼比小于 1，会回弹一点）；颜色、透明度用 effects（临界阻尼，不回弹）。再按动的东西多大分 fast / default / slow：按钮、一行字这种小范围变换用 fast，卡片、面板用 default，整屏的移动用 slow。弹簧随时可以改终点，改的时候接着当前速度走。下面是项目里 material3 1.5.0-alpha25 的实际取值；开「减少动画」时整套换成 standard 方案。

背景：封面揉成的网格

AMLL 的默认背景是把封面压低对比 → 饱和度 ×3 → 对比 ×1.7 → 亮度 0.75 再模糊，贴到一张由控制点生成的网格上（每张封面随机挑一套控制点），网格本身不动，纹理慢慢转；四周压暗到 60%；低频响度越大纹理放得越大。换封面时新网格叠在上面 0.5 秒内淡入，淡完删掉旧的。点下面的封面看换封面的过渡。

切歌：画面怎么换

分两种。手动切歌（点下一首、通知栏、耳机）：AMLL 把旧歌词撤掉，新歌词的每一句都从视口下方两个屏高处同时出发，用慢弹簧（刚度 90、阻尼 15）飞到各自的位置，不错峰；因为起点相同，句子一开始挤在一起，越接近越散开。封面背景 0.5 秒淡入。第 01 节的「切到下一首」就是这个。 自动接歌是我们自己的问题：现在要等淡化全部做完才换主播放器，播放页、通知栏、状态栏歌词才换到下一首；8–12 秒的淡化里，下一首可能已经唱了一两句。

项目改后现在
换页时机自动接歌时，在换页点把下一首提升为主播放器：交叉点（等功率、低频交接、尾奏承接都是 t = 0.5；切拍就是切点）和下一首第一句前 0.3 秒取早的，但不早于上一首最后一句唱完。上一首转成「尾巴」继续按原曲线淡完再释放淡完（t = 1）才 promote
歌词预载下一首时顺手把歌词取回来进缓存，换页时直接有；新歌词从下方飞入，时钟用下一首自己的进度换主后才去取歌词，第一句可能已经过去
页头、封面、背景和手动切歌一样：小圆封面淡入、网格 0.5 秒淡入、页头配色过渡同，但晚了一个淡化长度
过渡动画（圆环 / 封面描边）不变，仍按整个淡化时长画；换页点之后画在新封面上—
通知栏、状态栏歌词、小组件跟着主播放器在换页点一起换（它们都读 MediaSession）淡完才换

首尾静音AutoMix 会去掉开头和结尾的静音离线分析算了第一个 / 最后一个有声位置，但接歌时没用它裁照做上一首的淡出按「最后有声处」结束，而不是文件末尾；下一首从「第一个有声处 − 150 ms」开始放（切拍仍对齐它自己的小节首拍）
变速对拍变速 + 对拍上一首在淡化开始时一下变到目标速度（±6% 内）调整改成在淡化的前 1/4 里分 8 步渐变到目标速度，避免一下变调感；每步要真机听有没有咔嗒声，有就退回一步到位
整张专辑专辑不过渡照样叠照做下一首和这首 albumId 相同、没开随机时，不叠、直接无缝接；「上一次接歌」记一条「同一张专辑，直接接」
流派、上传、购买可能不做动态过渡—不做我们的歌没有可靠的流派数据；本地 / 云盘歌曲本来就能分析，不需要排除
Hi-Res 无损不可用24 位 FLAC 照样能接不做我们的混音在解码后做，和音质档位无关，没有理由跟着限制
默认值AutoMix 默认开总开关默认关不改老用户的习惯不动

08

平板、折叠屏和电视

舞台只拿安全区，页头、专注栏、控制条都是各自布局原有的。字号按宿主基准等比；视口宽度超过 1024 时模糊不乘 0.8。电视没有触摸，不接收拖动和点按，景深模糊默认关、帧率按宿主的 30 fps；窗口太矮时和其它模式一样回到经典。每台都是真跑的，切过去才开始动。下面的按钮可以把所有设备换成「经典（M3E 调后）」，经典按各布局现有的 LyricsSizing 预设排版。

09

动画面板里的设置

AMLL 原组件的选项大多是给开发者调的（锚点、弹簧参数、隐藏已唱句……），面板里只放用户看得懂、会想改的五项，其余 8 项保持原默认值，面板底部照其它移植模式的写法注明。改这里的设置，第 01、03、08 节里 AMLL 的舞台会跟着变。

设置选项（默认加粗）说明
背景网格 · 流光 · 纯色流光＝宿主的流光 / 律动背景；纯色＝播放页 surface
字号×0.8 – ×1.4，默认 ×1×1 时手机 30 sp，平板、电视按宿主基准等比
景深模糊关 · 弱 · 中 · 强按 AMLL 的档位乘 0 / 0.5 / 1 / 1.5；Android 12 起；电视和低内存设备默认关
长音强调开 / 关唱满 1 秒以上的字逐字放大、发光
对唱与和声开 / 关认「男：/女：」前缀和括号和声；关掉就按原文一行一行显示
保持默认的 8 项：对齐锚点（居中）、对齐位置（35%）、弹簧开关、缩放开关、隐藏已唱句（关）、渐变宽度（0.5 字）、位移和缩放弹簧参数、脏词遮罩（关）。
10

实现和分期

经典的改动都在 PlayerParts.kt 一个文件里，和别的部分互不依赖，可以先做。歌词部分是 ui/player/stage/modes/ 下一个新模式，LyricVisualizer 接口不用改（Rush 已经加过 interactive 和 seek）。切歌部分改 playback/ 里的三个类和队列面板、设置页各一处。

文件内容
PlayerParts.kt（经典）自动滚动不动；LyricRow 的放大进度改 fastSpatialSpec，lyricLayerScale 的上限在 API 28 起放到 1.03；所有句统一 FontWeight.Bold；KaraokeLine 没唱到的透明度从 1 用 defaultEffectsSpec 降到 0.45（和行透明度同一个弹簧）；LyricsList 外面包 AnimatedContent（按歌曲区分，每份歌词各自的 LazyListState）：进 slideInVertically(defaultSpatial) + fadeIn(slowEffects)，出 fadeOut(fastEffects)，上一首反向
AmllVisualizer.ktid "amll"、显示名「AMLL」、order 2（Rush 后面）；ModOrigin("AMLL", "core 0.7.2", "amll-dev", "AGPL-3.0", kind = "开源组件")；interactive = true；hostSubtitles = false（翻译排在句子里）；hostBackground = false，背景选「流光」时在 Background() 里直接画宿主的 LyricsBackdrop
AmllLyrics.ktStageLine → 句组（主句 / 和声 / 对唱），「男：女：合：」前缀和括号和声在这里识别；算 ≥7 秒的间奏区间
AmllTimeline.kt正在唱的集合、亮着的集合（新句开始才熄旧句）、焦点句、跳转判定
AmllLayout.kt行高前缀和、35% 对齐、间奏插入、错峰延迟（50 ms，过当前句后 ÷1.05）、模糊档位
AmllSpring.kt阻尼振子解析解 + 延迟队列（AMLL 的 utils/spring.ts，其中求解部分注明 MIT · pushkine）；按句间隔取刚度
AmllLine.kt一句的绘制：按词 DstIn 渐变遮罩、上浮、长音逐字变换和辉光、亮暗两层插值。不用 LazyColumn：所有句子在一个自定义 Layout 里，位置和缩放在 graphicsLayer 里读弹簧数组，逐帧只重画不重组
AmllDots.kt / AmllMesh.kt三点的进场、点亮、呼吸、退场状态机；网格背景（drawVertices + BitmapShader，0.5 秒淡入）
CrossfadeController.kt换页点到了就 promote，旧播放器转成「尾巴」按原曲线淡完再释放；CrossfadeStatus.transition 延续到淡完；同专辑不过渡；变速分 8 步渐变
AutomixPlanner.kt新字段 switchAtMs；淡出终点改用 outroMs，下一首起点改用 introMs − 150
MusicViewModel.kt预载下一首地址时顺手把歌词取进缓存；队列行的开关动作
PlayerSheets.kt / SettingsSubScreens.kt队列里的「切歌过渡」行；交叉淡化时长滑块卡片（电视上左右键一格 1 秒，复用 tvSliderKeys）
