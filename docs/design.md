# myMusic 界面与交互设计

## 设计方向

界面以唱片封面和正在播放的内容为视觉中心，其余区域保持安静、整齐。强调色只用于当前选中项、播放状态和遥控器焦点，不给每张卡片叠加渐变或阴影。

### 基础色板

Android 12 及以上默认使用系统动态配色；Android 6–11 使用下列内置配色，并始终提供浅色、深色和跟随系统三种模式。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 深松绿 | `#006B5F` | 浅色主题主色、播放状态 |
| 青瓷绿 | `#52DBC4` | 深色主题主色、焦点描边 |
| 墨青 | `#101817` | 深色背景 |
| 雾白 | `#F7FBF9` | 浅色背景 |
| 石板灰 | `#3F4946` | 次要文字和图标 |
| 错误红 | `#BA1A1A` | 播放、网络和下载错误 |

### 字体

使用系统无衬线字体，避免联网下载字体并保证中文在各厂商 Android 6 设备上可用。页面标题使用 Medium 字重，正文使用 Regular；歌曲名最多两行，歌手和平台信息最多一行。电视端正文不小于 16sp，主要标题不小于 24sp。

## 自适应布局

布局由可用宽度、窗口尺寸和设备类型共同决定，而不是仅用设备型号判断。

```text
手机（compact，宽度 < 600dp）
┌──────────────────────┐
│ 页面内容 / 单列列表    │
│                      │
├──────────────────────┤
│ 迷你播放器            │
├──────────────────────┤
│ 首页 搜索 音乐库 设置  │
└──────────────────────┘

平板（medium / expanded）
┌────┬─────────────────┐
│ 导 │ 双列或多列内容    │
│ 航 │                   │
│ 栏 │                   │
├────┴─────────────────┤
│ 迷你播放器            │
└──────────────────────┘

电视（leanback 或宽度 ≥ 960dp 的横屏大屏）
┌────────┬──────────────┬───────────────┐
│ 导航栏 │ 主内容网格    │ 可选详情面板   │
│ 88dp   │ 3–5 列       │               │
│        │              │               │
├────────┴──────────────┴───────────────┤
│ 常驻播放条                            │
└───────────────────────────────────────┘
```

- 手机使用 Material 3 `NavigationBar`，平板与电视使用 `NavigationRail`。
- 网格列数由实际宽度计算，专辑和歌单卡片保持统一宽高比。
- 所有可点击元素同时支持触摸、鼠标、键盘和 DPAD；电视端最小触控/焦点区域为 48dp。
- 焦点态使用 2dp 主色描边和轻微放大，不仅依赖颜色；无动画偏好下取消放大过渡。
- 播放页在手机上使用全屏页面，在大屏上使用封面、控制区、歌词的双栏布局。
- 不引入 `androidx.tv`，焦点、导航和播放器均使用 Compose Foundation、Material 3 与 Media3。

## 页面与交互

1. **首页**：平台切换、推荐歌单、排行榜、歌单分类；内容可以进入详情或直接播放。
2. **搜索**：单曲、歌单、专辑等类型共用搜索框，保留搜索历史，支持分页和错误重试。单曲默认跨平台聚合，按作品合并结果并展开各平台来源；歌单、专辑和链接仍按当前平台处理。
3. **音乐库**：收藏、最近播放、本地歌单、平台账号和用户歌单。
4. **详情**：歌单、专辑、排行榜共用歌曲列表和批量操作，避免三种页面出现不同交互。
5. **播放器**：队列、顺序/随机/循环、进度、歌词、音质、收藏和下载；后台播放由 MediaSession 服务负责，ExoPlayer 使用 LRU 自动缓存，已下载歌曲优先从本地文件播放。歌词支持标准 LRC 的逐行同步高亮和自动滚动，增强 LRC 支持逐词高亮；播放页同时展示当前播放源与换源入口。
6. **下载**：显示排队、下载中、完成和失败状态，可暂停、取消、删除和重新下载。
7. **设置**：主题、动态配色、默认平台、音质、缓存、账号、开源许可和上游项目说明。

## 设计自检

初稿若退化为“深色背景加单一亮色的通用音乐模板”，则不增加装饰性渐变，而把差异放在真实专辑封面、平台切换方式和从手机底部导航到电视侧边导航的连续布局上。卡片只用于表示可独立操作的媒体对象，不把普通文本和设置项全部包装成相同样式的卡片。页面文案直接描述结果，例如“无法获取播放地址，请更换音质或平台后重试”，不使用空泛的“出了点问题”。
