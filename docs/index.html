myMusic
界面 特性 设计稿 社区

Android 6.0+ · Compose · Material 3

把五个平台
收进一个播放器

myMusic 聚合网易云、QQ、酷狗、酷我、咪咕的榜单、歌单与单曲，按同一录音合并，自动换源播放。手机、平板、折叠屏、双屏和电视用同一套焦点与播放操作。

Features

它能做什么

🧭

跨平台聚合

单曲、专辑、歌单并行查询已启用的平台，按同一录音合并；逐条标出完整、试听、VIP 或无音源。

🔁

换源播放

当前平台没有播放地址时，在其他平台按需检索同一版本并接续播放，保留播放进度。

🎨

海报墙

播放队列铺成一面可以四向拖动的封面墙，点一格就地放大，再点就从这首开始放。

📱

桌面小组件

六款 Glance 组件：正在播放、歌词、听歌模式、榜单、歌单与快捷入口，颜色跟随 App 外观。

📖

折叠屏与双屏

按系统报来的折痕分栏：书本姿态左页封面右页歌词，桌面姿态上半屏歌词、下半屏控制。

🎚️

均衡器与响度

五段以上实时均衡；用平台返回的响度元数据做音量均衡与峰值限幅，不修改音频文件。

☁️

音乐库同步

自建歌单同步到 GitHub Gist 或 Gitee，三版本逐歌单合并，冲突时让你选，删除用墓碑。

🎤

听歌识曲

录音同时查网易云与酷狗两个通道，结果按歌名歌手合并，点一条直接播放。
