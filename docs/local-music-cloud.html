本地的歌也能跟着歌单换设备

这份稿子回答三件事：扫描本机音乐并补上封面和歌词；把本地歌上传到网易云盘或自己的 WebDAV，这样加进自建歌单后，换一台设备也能直接播；音乐库同步在 GitHub Gist、Gitee 代码片段之外，多一个 WebDAV。 思路是：同步文件里不放音频，只放“这首歌是哪个文件、传到了哪里、匹配到了哪首”。每台设备按这几条线索自己找能播的那一份，一份都找不到就如实显示“只在某台设备上”，不删歌单里的条目。

接口依据：docs/local-music-cloud-sync-spec.md 新页面 2 个：本地音乐、设置 › 本地音乐 同步位置 3 个 同步文件 v3，旧版本读得懂
00

结论

扫描和匹配都在本机完成，不依赖任何云盘；难的是跨设备，靠“文件指纹 + 云端位置 + 匹配结果”三条线索解决。网易云盘有完整的上传和播放链路，做；QQ 音乐云盘只有读取，上传协议没有公开闭环，这次只做只读；WebDAV 是标准协议，既能放歌，也能放同步文件，一个账号两处用。

这台设备有文件同一个文件（按首尾 64KB + 大小算指纹）在哪台设备上都认得出，直接播本机文件。
传到了云盘按同步过来的云端位置播：网易云盘走现有取流，WebDAV 带账号直接流式播放。
匹配到了平台版本文件和云端都没有时，用匹配到的那首平台歌播（可关）。界面写明“用网易云的版本”。
哪里都没有灰掉，写“只在 Pixel 8 上”，点开告诉用户怎么办。歌单条目保留，同步照常。
01

从扫描到另一台设备播放

扫描系统媒体库 + 用户选的文件夹。只读文件，不改、不传。READ_MEDIA_AUDIO / 文件夹授权
匹配先按标签搜，分数够就用；不够再取 3 秒做听歌识曲。拿到封面、歌词、标题。复用识曲和换源的匹配打分
加进歌单和平台歌一样加。同步已连接、这首又只在本机时，提示一句并给“上传”。歌单里记的是文件指纹
上传一首一首传到网易云盘或 WebDAV；网易云曲库里有的歌秒传。串行、可取消、先查容量
另一台设备歌单同步过来，按“本机 → 云端 → 平台版本”找能播的一份。找不到也不删条目
02

入口和本地音乐页

「我的」里，三张磁贴下面加一行「本地音乐」，和「汽水天天送会员」并成一组。本地音乐页的结构照「下载」页：顶上一张占用卡片，分段条显示已上传、只匹配、没匹配三类；再往下是播放全部、筛选和歌曲列表。本机 / 云端两个视图用现有的连接按钮组切换（右边两张图是同一页的两个视图）。

  • 权限：第一次打开本地音乐时是空状态页，主按钮“允许读取音乐”（Android 13 起 READ_MEDIA_AUDIO，更早是读存储）；拒绝后按钮换成“改为选择文件夹”，走系统文件夹选择器，不需要权限。
  • 扫描：后台低优先级，按修改时间增量；首次扫描时卡片换成进度（“正在扫描 · 已找到 812 首”），列表边扫边出现。消失的文件先标“文件不在了”，不自动删记录。
  • 下载的歌：myMusic 自己下载的文件已经在「下载」里，扫描时跳过下载目录，不重复出现。
  • 电视：入口照样有，只扫媒体库；电视上通常没有系统文件夹选择器，检测不到时隐藏“添加文件夹”。
03

一首歌：匹配和上传

在歌曲行点 ⋮ 打开「歌曲信息」，在这里看匹配结果、云端副本和文件。匹配只改应用里显示的封面、歌词和标题，不写回文件，规格里也建议第一版不碰文件标签。上传面板可以从单曲、多选和本地音乐页顶部的“上传…”打开。

匹配的顺序（照规格 5.1）：标题和歌手都有 → 在已启用平台里搜，用现有的匹配打分，≥ 0.85 直接用；没有标签或分数不够 → 取 3 秒 8kHz 单声道片段，本机算指纹，交给网易云识曲；还不行 → 标“没匹配”，等用户手动换。识曲只发指纹，不发音频。
04

换一台设备打开同一个歌单

在另一台手机上打开同步过来的「通勤路上」。每首本地歌按 本机文件 → 云盘 / WebDAV → 匹配到的平台版本 的顺序找能播的那份，用现有徽标说明是哪一份。哪里都找不到的歌灰掉，写明文件在哪台设备上；这需要同步文件里多记一个上传设备名（规格里没有，见第 07 节）。

05

设置 › 本地音乐

设置首页第二组「平台账号、音乐库同步」后面加「本地音乐」（说明：扫描范围、封面歌词匹配与上传）。本地音乐页右上角的 ⚙ 也直接进这里。WebDAV 账号只有一个：在这里配，或者在音乐库同步里选 WebDAV 时配，是同一个表单、同一份密钥。

06

音乐库同步：多一个 WebDAV

实现上是同步接口的第三个实现：同步文件 mymusic-library.json 放在 WebDAV 目录里，读写用 GET / PUT，ETag 防止两台设备同时写覆盖对方。合并规则、冲突处理、自动同步都和 Gist / Gitee 一样。同步位置选 WebDAV 时不需要令牌，适合不想用 GitHub、Gitee 的人，也适合 NAS 用户。

三个存放位置能做到什么

下表按规格文档整理，不另外验证。“这次做”一列就是落地范围。

网易云盘QQ 音乐云盘WebDAV

08

同步文件 v3

版本号从 2 升到 3。一首本地歌在歌单里长这样（只多几个可选字段，旧版本读到会忽略）：

{
  "key": "local:sha256:9f3a…c41e",        // 主身份：文件首尾各 64KB + 大小算出的指纹，不用云盘 ID
  "title": "雨季备忘", "artist": "示例歌手", "durationSec": 252,
  "local": { "hash": "sha256:9f3a…c41e", "fileName": "雨季备忘.flac", "fileSize": 33973452,
             "device": "Pixel 8" },              // 新增：上传前用来写“只在 Pixel 8 上”
  "remote": { "provider": "netease_cloud", "id": "1990…", "playableId": "",
              "status": "ready", "uploadedAt": "2026-11-08T21:14:03Z" },
  "match":  { "provider": "netease", "id": "1901371647", "confidence": 0.96,
              "method": "audio", "matchedAt": "2026-11-08T20:02:11Z" }
}
  • 合并：歌单层面仍按修改时间后写的为准，不重写同步；同一首歌两边都有时字段取并集，remote 取上传时间新的，match 取分数高的。
  • 删除：本机删了文件不写墓碑，歌单条目保留；云盘里删了只把 remote.status 改成 deleted。“哪里都放不了”永远不是删除歌单条目的理由，这条写进合并测试。
  • 体积：只同步加进歌单或收藏的本地歌，不同步整个本地库。每首多 150–250 字节；同步文件超过 1 MB 时提示，不悄悄截断。
  • 永远不进同步文件：音频、歌词正文、封面图片、WebDAV 密码、播放地址、本机文件路径。
  • 一个 WebDAV 位置下放两类东西：myMusic/mymusic-library.json（同步文件）和 myMusic/music/<指纹前两位>/<指纹>.<扩展名>（上传的歌）。歌的路径按规格 8.3，只是多套一层 music/，免得和同步文件混在一起。

出错时用户看到什么

情况界面处理
网易云盘容量不够上传面板里网易云盘那行说明“还差 1.2 GB”，按钮不可点开始前按已用 / 总容量和待传总大小检查，不进队列
单个文件超过 500 MB“有 1 首超过 500 MB，会跳过”其余照传
网易返回 −460队列暂停；我的页那行写“上传暂停：网易云要求重新验证”不自动重试，用户点“继续”才再试；退避
转码超过 10 分钟没完成这首标“上传失败”，可重试状态轮询 3–5 秒一次，最长 10 分钟
WebDAV 401“WebDAV 密码不对或已失效”，点进去改密码不清掉已上传的位置记录
WebDAV 不支持断点播放时第一次提示“这个服务器要整首下载后才能播”退化为整文件读取
云端连不上（断网）空心点 + “云端暂时连不上”不写进同步文件，网络恢复自动好
本机文件被删或移走本地音乐里标“文件不在了”，可清理歌单条目保留；有云端副本时照常从云端播
没给读取音乐权限空状态 + “改为选择文件夹”文件夹授权不需要权限

隐私说明、README 和许可

位置加什么
隐私说明 · 新增「本地音乐」扫描只读取文件信息和标签，不改文件，也不会自己上传。自动匹配时，会把歌名和歌手发给已启用的平台搜索；标签不够时，在本机把 3 秒片段算成指纹，只把指纹发给网易云识曲，不发音频。只有你点了上传，文件才会传到你选的网易云盘或 WebDAV。
隐私说明 · 「写入你选择的云端」加一句：选 WebDAV 时，同步文件写在你的 WebDAV 目录里；WebDAV 密码只存在本机，不进同步文件。
README · 功能列表本地音乐：扫描手机里的歌，自动补封面和歌词；可以上传到网易云盘或自己的 WebDAV，加进歌单后换设备也能播。
README · 音乐库同步同步位置可选 GitHub Gist、Gitee 代码片段或 WebDAV。
THIRD_PARTY_NOTICES上传流程参考的开源实现（规格第 15 节列出的项目）如果照搬了代码或协议细节，按它们各自的许可登记在这里；README 不写接口细节。

落地顺序

WebDAV 同步位置不依赖本地音乐，先做；本地库和匹配先在本机成立；最后才碰云端上传。

P1

WebDAV 同步位置

  • 同步接口第三个实现，ETag 防覆盖
  • 连接表单、测试连接、自签名开关
  • 电视扫码配置加 WebDAV
P2

本地库

  • 权限、媒体库 + 文件夹扫描、增量
  • 本地音乐页（本机视图）、播放本地文件
  • 加进歌单（local: 条目）
P3

匹配

  • 标签搜索 + 3 秒识曲
  • 歌曲信息、换一个匹配
  • 同名 .lrc、标题显示策略
P4

同步 v3 和可用性

  • SyncTrack 新字段、合并测试
  • 本机 → 云端 → 平台版本 的解析
  • “只在某设备上”状态和面板
P5

上传和云端播放

  • WebDAV 上传 / 播放
  • 网易云盘上传状态机、秒传、容量
  • 上传面板、队列、云端视图
P6

QQ 云盘只读

  • 列表、已匹配的播放、删除
  • 原文件标为不能播
  • 隐私说明、README

不做的事

  • QQ 音乐云盘上传（等有真机抓包确认参数后再说）。
  • 改写文件标签、把封面写进文件。
  • 把整个本地库清单同步到云端；只同步加进歌单和收藏的。
  • 音频、歌词正文、封面、WebDAV 密码进同步文件。
  • 并发上传、扫描时自动上传。
  • 把“云端删除 / 暂时连不上”当成用户删了歌。
上线前要在真机上确认的（规格第 14 节）：网易云盘没匹配上的原文件用哪个地址播；simpleSong.id 和 songId 是否相同；Gist / Gitee 对 1 MB 以上同步文件的限制；坚果云对单次 PUT 的大小限制。
依据：docs/local-music-cloud-sync-spec.md（接口、数据模型和限制，按要求不另外验证）；myMusic 当前的 LibraryScreen（我的）、LibraryCollections（下载页占用卡片）、SyncScreens（音乐库同步与连接）、components/Lists.kt、Badges.kt、Buttons.kt、SettingsCommon.kt。
