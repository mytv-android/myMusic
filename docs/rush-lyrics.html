歌词动画加一种：Rush

Rush（shub39/Rush，GPL-3.0，7.2.1）是一个照 Spotify 歌词页做的歌词应用。它的歌词页有几个特点：底色从封面取，左对齐的粗体大字，当前句停在上三分之一处，离当前句越远的句子越模糊，逐字唱到时有一道羽化扫光，间奏用三个点表示进度，背景有六种，其中三种会跟着音乐动。 这里把这套歌词页做成全屏歌词的第 10 种动画「Rush」，放在动画面板里经典的旁边。页头、进度条和播放控件仍是 myMusic 自己的，不换。

结论

只移植 Rush 歌词页里画歌词和背景的部分，按现有的 LyricVisualizer 接口写成一个模式。分享卡片、LRCLIB 纠错、Genius 纯文本歌词、自定义取色器这些不属于全屏歌词，不搬。律动背景用 myMusic 自己从解码后的 PCM 算出的低中高频，不像 Rush 那样用系统 Visualizer，所以不需要录音权限。

一句话：全屏歌词页右上角 ✦ 打开动画面板，选「Rush」。整页铺上封面主色，歌词靠左排、当前句在上三分之一处放大，前后的句子缩到 80% 并按距离模糊，正在唱的那句逐字扫亮；手指拖动歌词时暂停跟随、去掉模糊，3 秒后回到当前句；点一句跳过去播放。

七项设置

Rush 原版的歌词页偏好有 14 项，跟全屏歌词有关的是下面这些。设置表只有数字、选项、开关三种控件，Rush 的六种背景放在一个连接按钮组里太挤，拆成「背景」和「律动样式」两行。Rush 的自定义颜色要取色器，现有设置表没有颜色项，改成「播放页」配色（直接用播放页那套深色）。

没放进面板的：行高、字距保持 Rush 默认（32sp / 0），面板底部写「原应用另有 2 项保持默认值」，和其它移植模式的写法一样。翻译、罗马音不单独设，跟应用里「歌词下面那一行」走；Rush 原版把罗马音放在每句下面，这里翻译也这样排，所以这个模式自己排副行（hostSubtitles = false）。

04

平板、折叠屏和电视

Rush 横屏时会把封面和歌名挪到左边 30%。myMusic 的平板、桌面姿态、电视都有自己的页头和工具栏，舞台只拿到安全区，所以不照搬它的横屏布局：歌词仍靠左排，句子最宽 720dp，安全区更宽时留在左侧。电视上没有触摸，不接收拖动和点按；景深模糊默认关；帧率按宿主的 30fps。窗口太矮时和其它模式一样回到经典。

05

Rush 原版里有什么，搬了哪些

Rush 歌词页的部分处理做法 / 原因
逐字歌词列表（SyllableSyncedLyrics）移植myMusic 的同步歌词大多带逐字时间，走这一套；没有逐字时间的句子按 charTimings 均分，和其它模式一致
逐句歌词列表（LineSyncedLyrics）合并它和逐字版差别只在没有逐字遮罩，合进同一个列表，没逐字时间就整句亮
六种背景移植两个 AGSL 着色器原样搬，参数接到 StageAudio
鲜艳 / 柔和配色改写Rush 用 kmpalette 取色；这里用现有的封面量化色，按 HCT 算柔和色和文字色
自定义颜色（取色器）不搬设置表没有颜色项，换成「播放页」配色
页头（封面、歌名、操作按钮）不搬全屏歌词页已有页头和 ✦、收藏
底部播放键随中高频发光不搬播放控件属于宿主，所有模式共用，不为一个模式改
Rush 模式（自动识别正在播的歌）、LRCLIB 纠错、Genius 纯文本、分享卡片不搬和全屏歌词无关；歌词来源仍是 myMusic 自己的
Google Sans Flex 等 11 种字体不搬不打包任何 Rush 的字体、图标和文案；用应用现有的 Roboto Flex 子集和系统中文字体
5 秒无操作隐藏控件不搬宿主已经有 4 秒自动隐藏

实现：一个新模式，两处小改接口

照现有 modes/ 的写法加文件，名字带 Rush 前缀防撞名；注册进 LyricVisualizers.all，order = 1，排在经典后面。

// ui/player/stage/modes/
RushVisualizer.kt     // object RushVisualizer : LyricVisualizer —— id "rush"、7 项设置、hiddenSettings = 2
RushLyricList.kt      // LazyColumn：锚点 1/3、缩放 / 模糊 / 透明度、拖动暂停 3 秒、点按跳转
RushSyllable.kt       // 一个词两层 + DstIn 羽化遮罩、逐字粗细、三点间奏
RushBackgrounds.kt    // 纯色 / 封面 / 流光 / 波浪 / 渐变 / 条纹；流光和条纹是 AGSL（API 33+）
RushPalette.kt        // 鲜艳 / 柔和 / 播放页三套底色与文字色

接口改动

interface LyricVisualizer {
    …
    /** true：舞台接收拖动和点按（宿主仍处理点在空白处唤醒控件）。现有模式都是 false。 */
    val interactive: Boolean get() = false

    /** 按当前设置决定要不要律动分析。默认返回原来的 wantsAudio；Rush 只在背景选「律动」时要。 */
    fun wantsAudio(settings: SettingValues): Boolean = wantsAudio
}

class LyricStageContext(…) {
    …
    /** 跳到某个时间播放；只给 interactive 的模式用。 */
    val seek: (Long) -> Unit
}

data class StageColors(…,
    /** 封面占比最大的颜色与降饱和压暗后的颜色，以及各自上面的文字色（对比度 ≥ 4.5:1）。 */
    val coverVibrant: Color, val onCoverVibrant: Color,
    val coverMuted: Color,   val onCoverMuted: Color,
)
  • 背景：hostBackground = false，自己的 Background 铺到系统栏下面（bleedToWindowEdges），和动感波光一样。
  • 边缘：列表上下两端用离屏 saveLayer + DstIn 渐变渐隐，和其它铺满的模式一致。
  • 频谱叠加：宿主的 reserveBottom 照常生效，列表底部让出频谱卡片那一截。
  • 缩略图：StagePreview 走减少动画分支：底色 + 三句（上句模糊、当前句满色、下句 20%），卡片窄时按 CARD_DP_PER_TEXT_SP 缩字号。
  • 换歌：按 lyricsKey == song.key 对歌，新歌词没到之前显示三点，不显示上一首的词。
  • 性能：只有当前句的词每帧重画；其它句的缩放和模糊在换句时动画一次。模糊用 RenderEffect，只画可见的十来句。AGSL 着色器每帧只更新 uniform，不重建 RuntimeShader（Rush 原版每次重组都新建一个，移植时修掉）。
