设计边界

只解决难输入，不做另一台遥控器

沿用现有同步配置与文件传输面板的深色松绿主题、随机会话和电视直连方式。面板只有两项任务，歌单与收藏同步仍留在已有同步中心。

文字写到正确的位置

从某个电视输入框发起时，会话只绑定这个输入框。焦点丢失就停下，不把文字写进后来碰巧聚焦的别的框。

音源由电视下载验证

手机只提交在线脚本地址。电视沿用现有自定义音源导入链路，校验成功后展示名称、版本和支持平台，失败不保存。

电视决定结果

手机上的“发送中”不等于已生效。电视确认写入或导入后再显示成功；网络失败时草稿原样保留，可以重试。

可交互主稿 · 360 dp

两项任务，一页完成

默认展示“文字输入”。切换“在线音源”可看单地址导入；下面的状态按钮可检查无焦点、发送中、失败和过期。

演示状态

默认动作足够明确

“替换原文 / 追加到末尾”先决定写入方式，再点“发送到电视”。右侧回车键是独立的“发送并确认”，不会误把换行当成提交。

手机看不到原文

电视只提供输入框名称和是否已有内容，不把现有文本、令牌或密码回传到网页。追加操作在电视端完成。

没有焦点也有退路

电视当前没有输入框时，写入按钮禁用并给出返回电视的提示；“音乐搜索”仍可直接使用，不会进入死路。

反馈节奏
点击后按钮立刻进入发送中；收到电视回执才显示成功。草稿只在电视确认写入后清空，失败永远保留。

使用路径

从扫码到电视生效

设置里有常驻入口，支持的电视输入框也有二维码图标。两条路径打开同一个临时会话，只是后者多绑定了一个输入目标。

电视打开面板

进入“设置 › 手机辅助输入”，或在输入框旁点手机图标。电视显示二维码、局域网地址和 10 分钟倒计时。

手机扫码连接

系统相机或扫码工具打开网页。页面先读取会话，显示“客厅电视”和当前可用目标，不要求登录。

选择任务并发送

文字可替换、追加或发送后确认；音源只需粘贴脚本地址。发送期间锁定重复提交，草稿不丢。

电视执行并回执

电视写入绑定输入框，或下载并验证脚本。手机显示真实结果；需要大屏操作时明确写“请在电视上继续”。

全设备预览

同一面板，按可用宽度重排

手机竖屏单栏；横屏与平板把连接状态放右栏；书本折叠态让铰链落在左右栏之间；电视本身只负责二维码与结果。

状态与反馈

不把“已经点了”当成“电视做了”

所有结果由电视回执驱动。每一种异常都保留下一步，过期页面不能继续写。

状态网页表现用户可以做什么
等待输入显示电视名称、绑定输入框和会话有效性，不显示电视里的原文。输入文字、切换写入方式，或改用音乐搜索。
目标丢失琥珀色提示“电视已离开这个输入框”，禁用替换、追加和确认。回电视重新点输入框旁的手机图标；仍可搜索。
发送中主按钮出现进度，相关控件暂时锁定，状态写“正在等待电视确认”。等待本次结果；不能重复点击制造乱序。
写入成功绿色回执写清“已替换 / 已追加 / 已发送并确认”，手机清空本次文字。继续输入下一段，或关闭页面。
音源导入成功显示脚本名称、版本和支持平台，不写“已可播放”这种未经验证的承诺。回电视调整音源顺序；再次粘贴可导入下一个。
下载或校验失败红色说明电视返回的具体原因，地址与文字原样保留，明确“未保存”。修正地址后重试，或回电视查看详细错误。
需要电视操作琥珀色卡片提示大屏上的下一步，不让进度条一直转圈。在电视完成确认；网页轮询后自动更新。
断连或过期整块表单禁用，说明二维码已过期或电视已关闭页面。扫描电视上的新二维码；旧页面不能复活会话。

M3 Expressive 组件对应

  • 任务切换：连接式分段按钮，选中项圆角弹到 22–24 dp。
  • 输入：56 dp 单行地址框、142–160 dp 多行文字框，焦点为主色 2 px 外环。
  • 动作：52–56 dp 主按钮；发送与回车组成 SplitButton，追加用 tonal 按钮。
  • 反馈：状态卡片、短 Snackbar、按钮内进度；不另开遮挡全屏的弹窗。
  • 形状：28–32 dp 大容器，16–20 dp 输入和状态容器，非对称种子形只用于标题图标。
  • 动效：只响应点击与结果；减少动态效果时移除弹性形变和进度旋转。

响应式与输入可达性

  • < 700 px：标题、表单、电视状态依次单栏；主要动作保持在第一张表单内。
  • ≥ 700 px：左侧任务、右侧连接与步骤，右栏 sticky 但不遮住输入。
  • 书本折叠：两等分栏加 72 px 中缝；输入、按钮和状态文字不落在铰链上。
  • 手机横屏：双栏压缩垂直空白，页面可滚动，不锁屏幕方向。
  • 触达：图标按钮至少 44 × 44 px；输入字号至少 16 px；支持键盘焦点与读屏标签。

落地契约

复用现有局域网面板底座

视觉和会话规则直接承接 LanPanelServer 与 SyncSetupTheme，不新建账号体系，也不开放通用按键注入。

会话与写入

  • 128 位随机会话只出现在二维码路径；只接受局域网来源，10 分钟过期。
  • 电视离开此页或进入后台即关闭服务；网页轮询发现失效后锁定表单。
  • 写接口沿用同源、自定义请求头、JSON Content-Type 与请求体上限检查。
  • 从输入框进入时绑定不可伪造的字段会话 ID；目标变化返回“目标丢失”，绝不改写别的字段。
  • 网页只收到字段名称、是否有原文、允许的动作；追加由电视端拼接，敏感原文不离开电视。

内容与音源

  • 通用文字最长 4096 字符；音源地址最长 2048 字符，前后空白由电视统一处理。
  • 一次只处理一个发送动作，电视按序回执；超时不重放写操作，先查询真实状态。
  • 在线音源复用现有下载、脚本校验和桌面插件依赖处理；验证失败不保存。
  • 不保存最近输入、剪贴板或令牌历史；页面刷新只保留当前草稿，不恢复已提交内容。
  • Android 17 的本地网络权限提示沿用现有 LocalNetworkHint。

本次不做

不复制歌单 / 收藏同步，不做播放遥控，不注入方向键或任意系统按键，不让网页读取平台 Cookie，不开放公网中继，也不把在线音源脚本上传到第三方转换服务。
